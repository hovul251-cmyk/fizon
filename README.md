# Fizion 0.10 — мессенджер для сообществ: Windows, браузер и телефон

Один и тот же Fizion работает:

- **приложением для Windows** (Tauri);
- **веб-версией в браузере** на компьютере (Chrome, Edge, Firefox, Safari);
- **на телефоне** (Android и iPhone) — в браузере или как приложение на главном экране; для Android можно собрать и отдельный APK.

Аккаунт и все данные общие: написал с телефона — сообщение сразу видно в приложении на компьютере.

Режимы:

- **Онлайн** — вход через почту, сообщения в реальном времени, файлы, голос и демонстрация экрана. Нужны бесплатные аккаунты Appwrite Cloud и LiveKit Cloud (настройка ниже, ~20 минут, почти всё делает одна команда).
- **Офлайн** — если файла `.env` нет. Пустое приложение на этом компьютере: без других людей, почты и голоса.

### Как устроено шифрование

Ничего включать и запоминать не нужно — всё происходит само:

- При первом входе создаётся твой ключ (ECDH P-256). Открытая часть лежит на сервере, закрытая — только на твоих устройствах. В интерфейсе её нет: её не видит ни сервер, ни администратор, ни ты сам.
- **Новое устройство** получает ключ от другого твоего устройства: оно публикует временный открытый ключ, а то, где ты уже входил, упаковывает для него твой ключ (ECDH + HKDF + AES-GCM). Сервер передаёт только шифр. Открой Fizion на старом устройстве — ключ переедет за пару секунд. Если старого устройства больше нет — «Создать новый ключ» в настройках (старые зашифрованные сообщения на новом устройстве тогда не откроются).
- **Личные**: общий ключ двоих (AES-256-GCM). **Группы**: случайный ключ группы, упакованный для каждого участника; ушёл участник — следующее сообщение уже под новым ключом. **Файлы и голосовые**: каждый файл — своим ключом, ключ едет внутри зашифрованного сообщения. **Звонки**: встроенное шифрование LiveKit с ключом из ключа пары или группы.
- Не шифруются сообщества (их видят модераторы), истории и лента. Push о зашифрованном показывает только «🔒 Зашифрованное сообщение». Поиск по истории на сервере зашифрованное не находит.
- В «Настройки → Шифрование» — список устройств с доступом к переписке: незнакомое можно убрать.

### Как устроены push и защита сообщества

Вторая серверная функция `fizion-events` запускается сама на каждое новое сообщение и звонок:

1. проверяет мут и медленный режим — нарушающее сообщение сервер сразу удаляет (модераторов это не касается);
2. рассылает push тем, кому нужно: в личных и группах — всем, в сообществах — только упомянутым через `@имя`, о звонке — срочно.

Push работают по стандарту Web Push (ключи VAPID создаёт `npm run setup`) в Chrome, Edge, Firefox, Android и на iPhone с iOS 16.4+ — когда Fizion добавлен на экран «Домой».

## Истории

- Кнопка «+» на своей аватарке вверху списка чатов (или меню аватарки → «Добавить историю»): фото или видео до 50 МБ, подпись.
- История видна всем 24 часа. Вокруг аватарки автора загорается **зелёное свечение** — везде: в полосе историй, в чатах, в профиле, в ленте. Нажал на аватарку — открылась история.
- Просмотр как в Telegram: полоски прогресса, ← → или клик по краям, пробел или зажатая мышь — пауза, Esc — закрыть. После просмотра свечение становится серым.
- Можно ответить на историю — ответ придёт автору в личные.
- Свои истории можно удалить; истёкшие приложение само удаляет вместе с файлами.

## Звонки и голосовые

- **Звонок в личке**: кнопки трубки и камеры в шапке переписки. У собеседника появляется входящий звонок с мелодией — «Принять», «Принять с видео» или «Отклонить». Во время разговора: микрофон, камера, показ экрана, окно можно развернуть на всю область. Не ответили за 45 секунд — звонок пропущен. Итог («📞 Звонок · 3:24» или «Пропущенный звонок») остаётся в переписке.
- **Голосовые комнаты** в сообществах — как раньше: заходишь в комнату, все в ней слышат друг друга, есть камера и показ экрана.
- **Голосовые сообщения**: пока поле ввода пустое, вместо «Отправить» — микрофон. Нажал — идёт запись, «Отправить» или «Отмена». В пузыре — плеер с «волной», по ней можно перематывать.

Звонки и голос идут через LiveKit, поэтому нужны ключи LiveKit в `.env.setup` (см. настройку).

## Плагины

Раздел **Плагины** сверху. Там:

- **Добавить плагин** — вставь код или открой файл: `.js` — плагин, `.css` — тема оформления. Перед установкой видно название, автора и что плагин сможет делать.
- **Примеры** — Кубик (`/roll`), Эмоции (`/shrug`, `/flip`), Напоминалка (`/remind 15 текст`), Статистика сообщений (своя панель), темы «Неон» и «Мята».
- **Как написать плагин** — инструкция и всё, что умеет объект `fizion`.
- Карточка плагина: включить/выключить, разрешения, команды, его панель, журнал ошибок, код, удалить.

Как это защищено: каждый плагин работает в отдельном Web Worker. У него нет доступа к окну приложения, сессии, паролю, файлам и интернету — `fetch`, `WebSocket` и прочее в песочнице отключены. Действовать он может только через `fizion` и только с разрешениями из заголовка: `commands`, `messages:read`, `messages:send` (не больше 5 сообщений за 10 секунд). Плагины хранятся на этом компьютере.

Пример самого маленького плагина:

```js
// @name Привет
// @permissions commands
fizion.command('hi', 'Поздороваться', (args) => 'Привет, ' + (args || 'всем') + '! 👋');
```

## Вход через почту

Два способа на выбор, на одном экране:

- **Код на почту** — вводишь адрес, приходит код из 6 цифр, вводишь его в приложении. Аккаунта нет — создаётся сам. Паролей нет.
- **Пароль** — регистрация с подтверждением почты кодом, вход по паролю, «Забыл пароль» — код на почту и новый пароль.

При первом входе приложение просит имя, имя пользователя (по нему тебя добавляют в друзья) и цвет аватара.

## Настройка онлайн-режима

Понадобятся [Node.js LTS](https://nodejs.org/) и [Rust](https://www.rust-lang.org/tools/install) (в установщике Rust согласись поставить Microsoft C++ Build Tools — «Разработка классических приложений на C++»).

### 1. LiveKit — голос и экран

1. Зарегистрируйся на [cloud.livekit.io](https://cloud.livekit.io) и создай проект.
2. **Settings → Keys**: создай ключ, скопируй **API Key** (начинается с `API…`), **API Secret** и адрес проекта вида `wss://имя-xxxx.livekit.cloud` (не адрес панели `cloud.livekit.io`!). Все три — из **одного и того же проекта**.
3. Проверить ключи можно сразу: `npm run check:voice`. Если при звонке была ошибка «invalid token» — значит, ключ и секрет не от того проекта или скопировались с лишними символами; команда это покажет.

### 2. Appwrite — аккаунты, база, файлы

1. Зарегистрируйся на [cloud.appwrite.io](https://cloud.appwrite.io) и создай проект, регион — **Frankfurt**.
2. **Overview → Add platform → Web**: имя `Fizion`, hostname `localhost`. Затем добавь вторую Web-платформу с hostname `tauri.localhost` — это адрес собранного приложения на Windows. Без этого вход будет отклонён.
3. **Overview → API keys → Create API key**, имя `setup`. Отметь права:
   `databases`, `tables`, `columns`, `indexes`, `rows`, `buckets`, `files`, `functions`, `execution`, `users`, `teams`, `sites`, `rules`, `platforms` (чтение и запись везде, где есть выбор). Скопируй секрет ключа.
4. В папке проекта скопируй `.env.setup.example` в `.env.setup` и впиши: адрес (`https://fra.cloud.appwrite.io/v1`), ID проекта (**Settings → Project ID**), ключ API и три значения LiveKit.
5. Выполни:

```
npm install
npm run setup
```

Скрипт сам проверит ключи LiveKit, создаст базу и все таблицы с индексами (включая истории, ленту, лайки и звонки), хранилище файлов, загрузит серверную функцию `fizion-api` с ключами LiveKit и запишет `.env` для приложения. Его можно запускать повторно — существующее он не трогает, а код функции обновит.

> `.env.setup` содержит секретный ключ, дающий полный доступ к проекту. Не отправляй его никому и не клади в архивы. Он нужен только для `npm run setup`; после настройки ключ можно удалить в консоли Appwrite.

6. **Auth → Settings** (в проекте):
   - **Email/Password** и **Email OTP** — включены;
   - **Password length** — от 8; **Sessions limit** — 10, чтобы можно было войти с нескольких устройств.

### 3. Почта

Ничего настраивать не нужно. На бесплатном тарифе Appwrite Cloud сам отправляет письма с кодами со своего адреса, а приложение просит их на русском. Свой адрес отправителя и свои шаблоны писем (Custom SMTP) доступны только на платном тарифе Pro — для начала они не нужны.

### 4. Запуск

```
npm run app
```

Первый запуск собирает Rust-часть 3–5 минут, следующие — секунды. Чтобы проверить чат вдвоём, запусти второе окно в браузере: `npm run dev`, открой http://localhost:1420 и войди с другой почтой.

Установщик для друзей: `npm run release` → `src-tauri\target\release\bundle\nsis\Fizion_0.6.0_x64-setup.exe`. Файл `.env` встраивается в сборку — у друзей ничего настраивать не нужно. В `.env` только адрес и ID проекта, это не секрет: доступ ограничивают права строк и серверная функция.

Если поднимешь свой Appwrite или LiveKit вместо облака, добавь их адреса в `csp` в `src-tauri/tauri.conf.json`.

## Веб-версия и телефоны

### Выложить в интернет

Веб-версия живёт на **Appwrite Sites** — в том же бесплатном проекте Appwrite, отдельный хостинг не нужен.

1. Добавь ключу API (Overview → Integrations → API keys) права **sites**, **rules** и **platforms** — чтение и запись.
2. В папке проекта:

```
npm run web:deploy
```

Скрипт соберёт веб-версию, выложит её, включит и напишет адрес вида `https://….appwrite.network`. Этот адрес он сам добавит в разрешённые платформы проекта — без этого вход с сайта не сработает. Если права platforms не дал — добавь вручную: Overview → Apps → Add app → Web, hostname — адрес сайта без `https://`.

Обновить сайт после изменений — та же команда. Собрать без выкладки: `npm run build:web` (файлы появятся в `dist-web/`, их можно положить на любой хостинг).

### На телефоне

Открой адрес сайта:

- **Android (Chrome)**: меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- **iPhone (Safari)**: кнопка «Поделиться» → «На экран „Домой“».

Fizion откроется без адресной строки, со своей иконкой, как обычное приложение.

На телефоне всё перестроено под палец: разделы — снизу, список чатов и чат открываются по очереди (стрелка «назад» в шапке), действия с сообщением — по нажатию на него, истории, лента и звонки — на весь экран, окна выезжают снизу.

### Чем отличается от приложения для Windows

| | Windows | Браузер на компьютере | Телефон |
| --- | --- | --- | --- |
| Чаты, истории, лента, плагины | да | да | да |
| Голосовые комнаты и звонки | да | да | да |
| Показ экрана | да | да | нет (браузеры телефонов не умеют) |
| Уведомления, когда Fizion свёрнут | да (трей) | да | да |
| Уведомления, когда Fizion закрыт | да, если в трее или автозапуск | push | push (iPhone — с экрана «Домой») |
| Автозапуск, трей, автообновление | да | — | — |

Камера и микрофон в браузере работают только на сайте с `https://` (у Appwrite Sites он есть). Плагины хранятся отдельно на каждом устройстве.

### Проверить на телефоне до выкладки

`npm run dev` пишет адрес вида `http://192.168.x.x:1420` — открой его с телефона в той же Wi-Fi сети и добавь `192.168.x.x` как Web-платформу в Appwrite. Микрофон и камера по такому адресу работать не будут (нужен https), остальное — да.

## Обновления через GitHub: запушил → у всех «Обновить»

Новый код больше не нужно ни собирать, ни раздавать руками. Отправил его на GitHub — дальше всё само:

1. GitHub Actions собирает новую версию (≈10–15 минут) с номером `0.9.<номер сборки>`.
2. Установщик для Windows и `latest.json` выкладываются в GitHub Releases, а веб-версия — на Appwrite Sites (если добавлен секрет `APPWRITE_API_KEY`).
3. Fizion у всех проверяет обновления сам: через 5 секунд после запуска, потом каждые 15 минут и когда возвращаешься в окно. Появляется плашка «Вышла новая версия Fizion 0.9.x» с текстом коммита и кнопкой **«Обновить»**:
   - в приложении для Windows — скачивается, ставится и перезапускается (с полоской загрузки);
   - в браузере — страница перезагружается уже на новой версии.

   То же есть в «Настройки → Уведомления и обновления» (кнопка «Проверить обновления»).

### Один раз: настройка

Нужны [Git](https://git-scm.com/download/win) и (по желанию) [GitHub CLI](https://cli.github.com/) — с ним всё делается одной командой.

```
gh auth login                                   # войти в GitHub (если поставил GitHub CLI)
npm install
npm run github:setup -- твой-логин/fizion
npm run push -- "Первая версия"
```

`github:setup` создаст ключ подписи обновлений (`~/.tauri/fizion.key`), пропишет адрес обновлений, привяжет папку к GitHub и — если есть GitHub CLI — сам создаст репозиторий и добавит секреты. Без GitHub CLI он покажет, какие 4–5 секретов вставить руками в `Settings → Secrets and variables → Actions`.

Репозиторий должен быть **публичным**: приложения скачивают обновления по открытой ссылке. Ключи в код не попадают — `.env` и `.env.setup` в `.gitignore`, а `npm run push` дополнительно проверяет, что их нет в git.

После первой сборки скачай установщик со страницы `Releases` своего репозитория и поставь его — **обновляться умеют только версии, собранные после настройки**. Дальше всё приходит само.

### Каждый раз

```
npm run push -- "Добавил реакции на истории"
```

Текст в кавычках увидят пользователи в плашке обновления. Если изменение мелкое и выпускать версию не нужно — допиши `[skip release]`. Несколько пушей подряд — соберётся только последний.

Ход сборки: вкладка `Actions` репозитория. Первые две цифры версии (`0.9`) берутся из `package.json` — поменяй там на `1.0.0`, и следующие версии пойдут `1.0.x`.

Ключ `~/.tauri/fizion.key` никому не отправляй и не теряй: без него новые версии не установятся у тех, у кого Fizion уже стоит.

## Android-приложение

Самый простой путь — веб-версия: открыть сайт в Chrome → «Установить приложение». Так работают и push-уведомления.

Отдельный APK из того же кода (Tauri Mobile):

1. Установи [Android Studio](https://developer.android.com/studio) и в нём SDK, NDK и «Android SDK Command-line Tools»; задай переменные `ANDROID_HOME` и `NDK_HOME` (инструкция: [tauri.app → Prerequisites → Android](https://v2.tauri.app/start/prerequisites/#android)).
2. `rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android`
3. Один раз: `npm run android:init`
4. Проверка на телефоне по USB: `npm run android:dev`; готовый файл: `npm run android:build` → APK в `src-tauri/gen/android/app/build/outputs/apk/`.

**Проще — пусть собирает GitHub.** После `npm run github:setup` (он создаёт ключ подписи Android `~/.tauri/fizion-android.p12` и кладёт его в секреты) каждый `npm run push` собирает и `Fizion.apk`, прикладывает его к релизу, а установленное приложение само видит новую версию: «Обновить» скачивает APK, Android ставит его поверх, данные сохраняются. Первый раз скачай `Fizion.apk` со страницы Releases и разреши браузеру установку приложений.

В APK работает всё, кроме push при закрытом приложении (в Android-приложении уведомления приходят, пока оно открыто или свёрнуто). Для них используй веб-версию с экрана «Домой».

### Обновление с прошлой версии

Распакуй новую версию поверх старой папки (`.env` и `.env.setup` останутся), затем:

```
npm install
npm run setup
npm run web:deploy
npm run app
```

`npm run setup` добавит новые таблицы (0.9: устройства и перенос ключей, ключи групп, «Смотреть вместе», прочитано, закреп, блокировки, вебхуки), новые столбцы (сцена, имя бота), адрес для ботов (функция `fizion-events` теперь принимает и вебхуки — на бесплатном Appwrite можно только 2 функции) и строки `VITE_VAPID_PUBLIC_KEY` и `VITE_HOOKS_URL` в `.env`. Перед этим он **проверит ключи LiveKit** — если звонки падали с «invalid token», он скажет, что не так. Старые данные не трогает.

С 0.9 шифрование включается само. Если в 0.8 ты включал его фразой — на устройстве, где оно уже работало, ничего не изменится; на остальных ключ переедет с этого устройства.
